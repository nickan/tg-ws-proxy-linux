# TG WS Proxy for Linux

**TG WS Proxy for Linux** — быстрый локальный MTProto WebSocket мост для Telegram Desktop в Linux, созданный для комфортной работы мессенджера без замедлений и блокировок РКН / ТСПУ.

Трафик маскируется под стандартные защищённые WebSocket-соединения Cloudflare и направляется напрямую к серверам Telegram без необходимости использования платных VPN.

## 🐧 Поддерживаемые версии и дистрибутивы Linux

Приложение упаковано в универсальный переносимый формат **AppImage**, который включает изолированное окружение CPython 3.11 и сертификаты `certifi`.

- **Архитектура**: `x86_64` (64-bit)
- **Минимальная версия glibc**: `2.17+` (совместимо со всеми современными и устаревшими версиями Linux)
- **Протестировано и гарантированно работает на:**
  - **Ubuntu**: 18.04 LTS, 20.04 LTS, 22.04 LTS, 24.04 LTS и новее
  - **Debian**: 10 (Buster), 11 (Bullseye), 12 (Bookworm)
  - **Linux Mint**: 19.x, 20.x, 21.x, 22.x
  - **openSUSE**: Leap 15.x, Tumbleweed
  - **Fedora**: 34, 35, 36, 37, 38, 39, 40, 41+
  - **Arch Linux**, **Manjaro**, **EndeavourOS**
  - **Отечественные ОС**: Astra Linux, РЕД ОС, Альт Линукс

## ✨ Особенности версии

- **Нативный GTK3 интерфейс в стиле Ubuntu (Yaru Dark)**:
  - Фирменные цвета палитры Ubuntu (Ubuntu Orange `#E95420`, графитовые карточки Adwaita `#383838`).
  - Интеграция с системным шрифтом ОС пользователя (`Cantarell 11` с субпиксельным сглаживанием Pango/Cairo).
  - Встроенный журнал логов с системным моноширинным шрифтом (`Source Code Pro 10`).
- **Telegram MTProto WebSocket Bridge (v1.10.4)**:
  - Автоматический пул доменов Cloudflare для обхода блокировок ТСПУ.
  - Динамическое переключение рабочих нод при сбоях сети.
- **Подключение в 1 клик**:
  - Кнопка **«Применить в Telegram»** мгновенно передает настройки `tg://proxy` в Telegram Desktop.
  - Кнопка **«Скопировать ссылку»** для ручной настройки.
- **Корректный жизненный цикл**:
  - Сворачивание в трей при закрытии окна.
  - Открытие окна по клику из трея или повторному клику по ярлыку (через IPC сокет).
  - Кнопка **«Выход»** полностью и чисто завершает все фоновые процессы без «висящих» процессов Python.

## 🚀 Запуск (AppImage)

1. Скачайте файл **`TgWsProxy.AppImage`**.
2. Сделайте его исполняемым:
   ```bash
   chmod +x TgWsProxy.AppImage
   ```
3. Запустите:
   ```bash
   ./TgWsProxy.AppImage
   ```

---

## 🛠 Сборка из исходников

Для сборки независимого AppImage пакета:

```bash
git clone https://github.com/nickan/tg-ws-proxy-linux.git
cd tg-ws-proxy-linux
chmod +x build_linux.sh
./build_linux.sh
```

Готовый файл появится в папке `dist/TgWsProxy-x86_64.AppImage`.
